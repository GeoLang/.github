GeoLang is an open-source geospatial platform: a versioned geodatabase, tile and analysis services, a map viewer, and an AI agent that turns natural-language questions into calls to geospatial tools.
It is licensed under AGPL-3.0 and runs self-hosted from published container images.

## Repositories

- [TileTopia](https://github.com/GeoLang/tiletopia): 3D Tiles, terrain and vector tiles
- [ViewTopia](https://github.com/GeoLang/viewtopia): unified viewer and agent
- [Ptolemy](https://github.com/GeoLang/ptolemy): enterprise geodatabase
- [Itinera](https://github.com/GeoLang/itinera): routing and network analysis
- [Geokode](https://github.com/GeoLang/geokode): geocoding and OSM ingest
- [Terrano](https://github.com/GeoLang/terrano): terrain and EO time-series
- [Nubis](https://github.com/GeoLang/nubis): point clouds and geostatistics
- [Panoptes](https://github.com/GeoLang/panoptes): AI/ML imagery
- [Geodukt](https://github.com/GeoLang/geodukt): ETL and GP service
- [Fluvius](https://github.com/GeoLang/fluvius): real-time geospatial stream processing
- [Geoplumb](https://github.com/GeoLang/geoplumb): windowed raster, vector and point cloud compute and tiles
- [Agora](https://github.com/GeoLang/agora): live map collaboration
- [Verne](https://github.com/GeoLang/verne): migration from ArcGIS, KML and file geodatabases
- [Projicio](https://github.com/GeoLang/projicio): CRS transforms
- [Jung](https://github.com/GeoLang/jung): cartographic rendering and symbology
- [GeoGit](https://github.com/GeoLang/geogit): versioned geodata
- [Topoi](https://github.com/GeoLang/topoi): computational geometry and WASM
- [Interiora](https://github.com/GeoLang/interiora): indoor mapping
- [Collecta](https://github.com/GeoLang/collecta): field data collection
- [TerraVista](https://github.com/GeoLang/terravista): Android SDK (camera, tile cache, navigation)
- [Fenestra](https://github.com/GeoLang/fenestra): OGC WMS/WFS/WMTS and server-side rendering
- [GeoLang](https://github.com/GeoLang/geolang): geospatial tool service
- [Sibyl](https://github.com/GeoLang/sibyl): LLM agent loop and sessions
